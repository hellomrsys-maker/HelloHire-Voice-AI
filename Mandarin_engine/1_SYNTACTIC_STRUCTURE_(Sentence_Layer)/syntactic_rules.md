# Mandarin Engine — Layer 1: Syntactic Structure (Sentence Layer)
## Chinese Topic-Comment, Disposal (把), Passive (被) & SVO Grammar Matrix

### 1. Topic-Prominent Architecture
Unlike English (Subject-Prominent), Mandarin is primarily **Topic-Prominent**:
```text
[Topic (已知信息 / Ground)] + [Comment (新信息 / Predication)]
例: 这本书 (Topic), 我已经读过了 (Comment).
例: 苹果 (Topic), 他吃了一个 (Comment).
```

### 2. The Disposal Construction (把字句)
```text
Subject + 把 (bǎ) + Definite/Disposed Object + Verb + Result/Direction/Aspect
Condition: Object must be specific/presupposed; verb cannot stand bare.
例: 我把作业做完了。(I completed the homework.)
例: 请把门关上。(Please close the door.)
```

### 3. The Passive Construction (被字句 / 叫 / 让)
```text
Patient + 被 (bèi) + (Agent) + Verb + Consequence/Result
Negative/Adversative origin, but standard modern passive.
例: 杯子被打破了。(The cup was broken.)
例: 计划被推迟了。(The plan was postponed.)
```

### 4. Serial Verb Constructions (连动式)
```text
Subject + V1 + (O1) + V2 + (O2)
Indicating purpose, manner, or consecutive actions.
例: 我们坐飞机去北京。(We take a plane to go to Beijing.)
例: 他去图书馆借书。(He goes to the library to borrow books.)
```

### 5. Clause Coordination & Subordination Markers
- Conditional: `如果...就...` (rúguǒ... jiù...), `要是...就...` (yàoshi... jiù...)
- Concession: `虽然...但是...` (suīrán... dànshì...)
- Causality: `因为...所以...` (yīnwèi... suǒyǐ...)
- Conjunction: `不仅...而且...` (bùjǐn... érqiě...)
