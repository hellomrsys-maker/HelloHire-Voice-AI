# Layer 4: Semantic Representation (Meaning Layer) — Indonesian Language Engine

## 1. Numeral Classifiers (Kata Penggolong)
Indonesian uses a rich system of numeral classifiers positioned between the number and head noun:
$$\text{Numeral Phrase} = \text{Number} + \text{Classifier} + \text{Noun}$$

### 1.1 Core Classifiers
| Classifier | Target Domain | Examples |
| :--- | :--- | :--- |
| **orang** | Humans, professionals, social roles | *seorang guru, dua orang anak* |
| **ekor** | Animals, birds, fish, insects | *seekor kucing, lima ekor burung* |
| **buah** | Inanimate objects, vehicles, buildings, abstract items | *sebuah mobil, tiga buah rumah, dua buah buku* |
| **lembar** | Thin flat items, paper, fabric, leaves | *selembar kertas, dua lembar kain* |
| **batang** | Long cylindrical rigid items, sticks, trees, cigarettes | *sebatang pohon, sebatang pensil* |
| **butir** | Small round objects, eggs, seeds, pearls | *sebutir telur, dua butir mutiara* |
| **pucuk** | Guns, letters, needles | *sepucuk surat, sepucuk senjata* |
| **bilah** | Sharp bladed objects, knives, swords | *sebilah pisau, sebilah pedang* |

*(The prefix `se-` represents the numeral 'one' fused to the classifier: seorang, sebuah, seekor, selembar).*

## 2. Pronominal Semantic Systems
Indonesian distinguishes between inclusive and exclusive 1st person plural pronouns:
- **Kita**: Inclusive 1st person plural (Speaker + Addressee: "you and me / all of us").
- **Kami**: Exclusive 1st person plural (Speaker + Others, excluding Addressee: "we, but not you").

## 3. Classical Indonesian Idioms & Proverbs (Peribahasa)
- *Ada udang di balik batu* (There is a shrimp behind the stone / a hidden motive).
- *Sambil menyelam minum air* (Drinking water while diving / killing two birds with one stone).
- *Besar pasak daripada tiang* (The peg is bigger than the pole / spending more than earning).
- *Tong kosong nyaring bunyinya* (An empty barrel makes the loudest noise / empty vessels make the most sound).
- *Air beriak tanda tak dalam* (Rippling water means it is not deep / shallow minds boast the most).
