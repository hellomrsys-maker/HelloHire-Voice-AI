### 2. The Politeness Particle Concord & Gender Split

Sentence-final politeness particles are grammatically sensitive to speaker gender and speech act type:

| Particle | Speaker Gender | Tone Category | Speech Act Function | Example | Gloss |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **ครับ** (*kráp*) | Male | High tone [45] | Declarative & Interrogative | *สวัสดีครับ* | "Hello (polite male)" |
| | | | | *ไปไหนครับ?* | "Where are you going? (polite male)" |
| **ค่ะ** (*kâ*) | Female | Falling tone [51] | **Declarative / Answer / Acceptance only** | *ขอบคุณค่ะ* | "Thank you (polite female)" |
| | | | | *เข้าใจแล้วค่ะ* | "I understand (polite female)" |
| **คะ** (*kái*) | Female | High tone [45] | **Interrogative / Question / Call only** | *จริงหรือคะ?* | "Is that true? (polite female question)" |
| | | | | *อาจารย์คะ* | "Professor! (polite female vocative)" |

#### Critical Orthographic Concord Invariant:
Mixing female particle tones constitutes an immediate sociolinguistic error in Standard Thai:
- **Violation**: \*ขอบคุณคะ (Declarative with high-tone *kha*) $\implies$ Correct to: *ขอบคุณค่ะ*
- **Violation**: \*อะไรค่ะ? (Question with falling-tone *khà*) $\implies$ Correct to: *อะไรคะ?*

### 3. Epistolary Formulas & Correspondence Etiquette

#### A. Formal Administrative / Business Correspondence
- **Salutation**:
  *เรียน ท่านผู้จัดการ / เรียน [ชื่อ/ตำแหน่ง] ที่นับถือ,* (*rian thâan phûu-càt-kaan...* - "Dear Respected Manager / Director,")
- **Opening Statement**:
  *เนื่องด้วย ทางเรามีความประสงค์จะ...* ("Owing to our intention to...")
- **Closing Formula**:
  *ขอแสดงความนับถืออย่างยิ่ง,* (*khɔ̌ɔ-sadɛɛŋ khwaam-náp-thɯ̌ɯ yàaŋ-yîŋ,* - "With utmost respect / Yours faithfully,")

#### B. Polite Informal Letter
- **Salutation**:
  *สวัสดีครับ/ค่ะ [ชื่อเพื่อน],* (*sàwàtdii kráp/kâ [Friend's Name],*)
- **Closing**:
  *ด้วยความปรารถนาดี,* (*dûay khwaam-pràatthanaadǐi,* - "With best wishes,")
