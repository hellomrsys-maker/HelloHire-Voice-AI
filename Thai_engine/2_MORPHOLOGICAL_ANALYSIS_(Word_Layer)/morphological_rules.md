# Morphological Analysis & Word Formation for Thai (Word Layer)
## Sovereign Engine: `Thai_engine` | Isolating Compounding

### 1. The Isolating Morphological Architecture
Thai possesses **zero inflectional morphology**: nouns do not inflect for case, number, or gender, and verbs do not inflect for person, tense, or mood. Word formation relies on **compounding, prefixation via bound morphemes, and reduplication**:

$$\text{Word} = \text{Root} \quad\lor\quad \text{Prefix} + \text{Root} \quad\lor\quad \text{Root}_1 + \text{Root}_2 \quad\lor\quad \text{Root} + \text{Maiyamok (ໆ)}$$

### 3. Compounding Patterns (*คำประสม*)
- **Noun + Noun**:
  - *น้ำแข็ง* (*nám-khɛ̌ŋ* = water + hard) -> "ice"
  - *รถไฟ* (*rót-fay* = carriage + fire) -> "train"
  - *แม่น้ำ* (*mɛ̂ɛ-nám* = mother + water) -> "river"
  - *ห้องน้ำ* (*hɔ̂ŋ-nám* = room + water) -> "bathroom / restroom"
- **Verb + Noun**:
  - *เปิดขวด* (*pə̀ət-khùat* = open + bottle) -> "bottle opener"
  - *ขับรถ* (*khàp-rót* = drive + carriage) -> "driving / car driving"
- **Noun + Adjective**:
  - *ใจดี* (*cay-dii* = heart + good) -> "kind-hearted / generous"
  - *ตาสว่าง* (*taa-sawàaŋ* = eye + bright) -> "enlightened / wide awake"

### 4. Reduplication (*การซ้ำคำ*) with Maiyamok (ໆ)
Thai utilizes the punctuation symbol **ๆ** (*Maiyamok*, `U+0E46`) to denote word reduplication:
1. **Intensification**: *เร็ว ๆ* (*rew rew*) -> "very quickly / hurry up!"
2. **Pluralization / Collectivity**: *เด็ก ๆ* (*dèk dèk*) -> "children"
3. **Approximation**: *บ่าย ๆ* (*bàay bàay*) -> "around the afternoon"
4. **Casual / Attenuative Action**: *เล่น ๆ* (*lên lên*) -> "just for fun / jokingly"
