# Pragmatics & Diglossic Register Specification for Tamil (Use Layer)
## Sovereign Engine: `Tamil_engine` | Diglossic Core

### 1. Diglossia (*Iraṭṭaimoḻi* இரட்டைமொழி / *Iraṭṭai Vaḻakku*)
Tamil exhibits pervasive diglossia spanning centuries:

| Feature | Formal Literary Register (*Centamiḻ* செந்தமிழ்) | Spoken Colloquial Register (*Koṭuntamiḻ* கொடுந்தமிழ்) | English Meaning |
| :--- | :--- | :--- | :--- |
| **"I come / am coming"** | *வருகிறேன்* (*varukiṟēṉ*) | *வர்றேன்* (*varṟēṉ*) | 1SG Present |
| **"He went"** | *சென்றான்* (*ceṉṟāṉ*) / *போனான்* (*pōṉāṉ*) | *போனான்* (*pōṉā*) | 3MSG Past |
| **"Eat food"** | *சாப்பிடுங்கள்* (*cāppiṭuṅkaḷ*) | *சாப்பிடுங்க* (*cāppiṭuṅga*) | 2PL/Polite Imperative |
| **"Is not / no"** | *இல்லை* (*illai*) | *இல்ல* (*illa*) | Negative particle |
| **"What?"** | *என்ன* (*eṉṉa*) | *என்ன* (*enna*) | Interrogative |
| **"Like that"** | *அவ்வாறு* (*avvāṟu*) / *அப்படி* (*appaṭi*) | *அப்படி* (*appaṭi*) | Adverbial manner |

- **Engine Policy**: The engine must never arbitrarily mix Centamil finite verbal morphology with Koduntamil phonetic abbreviations in the same clause.

### 2. Honorifics & Deference System
The address system strictly governs grammatical agreement:

```
Informal / Intimate:      நீ (nī)        -> Verb: -āy (-ஆய்)       (e.g. நீ படித்தாய்)
Formal / Honorific:       நீங்கள் (nīṅkaḷ) -> Verb: -īrkaḷ (-ீர்கள்)  (e.g. நீங்கள் படித்தீர்கள்)
Distinguished Third Pers: அவர் (avar)    -> Verb: -ār (-ார்)       (e.g. அவர் சொன்னார்)
Group / Supreme Hon:      அவர்கள் (avarkaḷ) -> Verb: -ārkaḷ (-ார்கள்) (e.g. அவர்கள் வந்தார்கள்)
```

### 3. Epistolary Conventions & Administrative Formulas

#### A. Formal Administrative / Business Letter
- **Salutation**:
  *மதிப்பிற்குரிய ஐயா / அம்மையீர் அவர்களுக்கு,* (*matippiṟkuriya aiyā / ammaiyīr avarkaḷukku,* - "To the Respected Sir / Madam,")
- **Opening Subject**:
  *பொருள்: ... தொடர்பாக.* (*poruḷ: ... toṭarpāka.* - "Subject: Regarding ...")
- **Closing Formula**:
  *இங்ஙனம்,*
  *தங்கள் உண்மையுள்ள,* (*iṅṅaṉam, taṅkaḷ uṇmaiyuḷḷa,* - "Yours faithfully,")

#### B. Colloquial / Friendly Letter
- **Salutation**:
  *அன்புள்ள [பெயர்], வணக்கம்!* (*aṉpuḷḷa [Name], vaṇakkam!* - "Dear [Name], Greetings!")
- **Closing**:
  *அன்புடன்,* (*aṉpuṭaṉ,* - "With love,")
