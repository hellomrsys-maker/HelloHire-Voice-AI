# Cantonese Syntactic Structure & Grammar Specifications (Sentence Layer)

## 1. Canonical Word Order & Double Object Inversion
Cantonese (Yue / 粵語) belongs to the Sinitic branch of Sino-Tibetan. While its basic clause structure is SVO, Cantonese exhibits a renowned structural divergence from Standard Mandarin in **Double Object Constructions (DOCs)**:
- **Cantonese Canonical DOC Order**: `[Verb] + [Direct Object (Theme)] + [Indirect Object (Recipient)]`
  - *畀本書我* (*pei2 bun2 syu1 ngo5*) = "Give the book to me" (Verb + DO + IO)
  - *教英文佢哋* (*gaau3 jing1 man2 keoi5 dei6*) = "Teach English to them"
- **Contrast with Mandarin**: Mandarin strictly mandates `[Verb] + [Indirect Object] + [Direct Object]` (*給我這本書*). Placing the indirect object first in colloquial Cantonese (*\*畀我本書*) is an unnatural calque.

## 2. Postverbal Adverbial Placement
Adverbial modifiers of degree or quantity often follow the verb in Cantonese, unlike Mandarin where they are strictly preverbal:
- Cantonese: *行先* (*haang4 sin1*) = "walk first" vs Mandarin: *先走* (*xiān zǒu*)
- Cantonese: *食多啲* (*sik6 do1 di1*) = "eat more" vs Mandarin: *多吃點* (*duō chī diǎn*)
- Cantonese: *睇吓* (*tai2 haa5*) = "take a look"

## 3. Classifier-Noun Syntax & Definiteness
Unlike Mandarin where classifiers (量詞) cannot directly precede a noun to express definiteness without a demonstrative (*這/那*), Cantonese classifiers can directly precede a noun to express **singular definiteness**:
- Cantonese: *隻狗好得意* (*zek3 gau2 hou2 dak1 ji3*) = "The dog is very cute." (Literally: "[CLF] dog very cute")
- Cantonese: *條路好闊* (*tiu4 lou6 hou2 fut3*) = "The road is very wide."
- Plurality can be marked by the plural classifier *啲* (*di1*): *啲書* (*di1 syu1*) = "the books".

## 4. Negation System (唔, 冇, 未, 咪)
Cantonese employs a distinct set of monosyllabic negators:
- **唔** (*m4*): General neutral declarative negator (corresponds to Mandarin *不*): *唔知* (don't know), *唔食* (don't eat).
- **冇** (*mou5*): Existential and perfective negator (corresponds to Mandarin *沒有*): *冇錢* (have no money), *冇去* (didn't go).
- **未** (*mei6*): Incomplete / Not yet negator (corresponds to Mandarin *還沒*): *未食飯* (haven't eaten yet).
- **咪** (*mai5*): Negative imperative / Prohibitive (corresponds to Mandarin *別 / 不要*): *咪行* (don't walk!).

## 5. Comparative Construction (過)
Cantonese forms the comparative postpositionally with *過* (*gwo3*):
$$\text{Item A} + [\text{Adjective}] + \text{過} + \text{Item B}$$
- *佢高過我* (*keoi5 gou1 gwo3 ngo5*) = "He is taller than me." (Mandarin: *他比我高*).
