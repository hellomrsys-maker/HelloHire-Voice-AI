# Hindustani Morphological Analysis & Inflection Rules (Word Layer)

## 1. Verbal Inflection System
All Hindustani verb infinitives end in **-ना (-naa)**: *bolna, karna, jaana, dekhna, aana, likhna*.
Stripping *-naa* yields the verb root/stem (*bol-, kar-, jaa-, dekh-, likh-*).

### Core Aspectual Suffixes:
1. **Habitual / Imperfective Aspect**:
   - Masc Sing: Root + *-ta* (*bolta*)
   - Masc Plur / Honorific: Root + *-te* (*bolte*)
   - Fem Sing: Root + *-ti* (*bolti*)
   - Fem Plur: Root + *-tin* / *-ti* (*boltin*)
2. **Continuous / Progressive Aspect**:
   - Masc Sing: Root + *raha* (*bol raha*)
   - Masc Plur / Honorific: Root + *rahe* (*bol rahe*)
   - Fem Sing: Root + *rahi* (*bol rahi*)
   - Fem Plur: Root + *rahin* (*bol rahin*)
3. **Perfective Aspect**:
   - Masc Sing: Root + *-a* / *-ya* (*bola, dekha, likha*)
   - Masc Plur: Root + *-e* (*bole, dekhe, likhe*)
   - Fem Sing: Root + *-i* (*boli, dekhi, likhi*)
   - Fem Plur: Root + *-in* (*bolin, dekhin, likhin*)
   - Irregular perfective stems:
     - *karna* -> *kiya, kiye, ki, kin*
     - *jaana* -> *gaya, gaye, gayi, gayin*
     - *dena* -> *diya, diye, di, din*
     - *lena* -> *liya, liye, li, lin*
     - *hona* -> *hua, hue, hui, huin*
4. **Future Tense**:
   - Formed by adding subjunctive endings + *-ga/-ge/-gi*:
     - *main bolunga / bolungi*
     - *tu bolega / bolegi*
     - *woh bolega / bolegi*
     - *tum bologe / bologin*
     - *aap bolenge / bolengi*
     - *hum bolenge / bolengi*
     - *woh (plural) bolenge / bolengi*

## 2. Copula and Auxiliary *Hona* Paradigms
- **Present Tense**:
  - *main hoon* (I am)
  - *tu hai* (thou art)
  - *woh / yeh hai* (he/she/it is)
  - *tum ho* (you are)
  - *aap hain* (you [hon] are)
  - *hum hain* (we are)
  - *woh / yeh hain* (they are)
- **Past Tense**:
  - Masc Sing: *tha*
  - Masc Plur / Honorific: *the*
  - Fem Sing: *thi*
  - Fem Plur: *thin*

## 3. Nominal & Adjectival Morphology
### Marked Adjectives (ending in -a in masc sing):
- Masc Sing Direct: *accha ladka* (good boy)
- Masc Sing Oblique: *acche ladke ko* (to the good boy)
- Masc Plur Direct: *acche ladke* (good boys)
- Masc Plur Oblique: *acche ladkon ko* (to the good boys)
- Feminine (all cases, all numbers): *acchi ladki, acchi ladkiyan, acchi ladkiyon ko*

### Unmarked Adjectives (ending in consonants or other vowels):
- Invariant across all genders, numbers, and cases (*sundar, saaf, laal, hoshyar*).
