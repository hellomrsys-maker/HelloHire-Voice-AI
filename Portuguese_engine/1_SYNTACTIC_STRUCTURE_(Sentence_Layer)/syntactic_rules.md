# Layer 1: Syntactic Structure (Sentence Layer) - Portuguese Engine (Português)

## 1. Primary Word Order Typology
Portuguese exhibits canonical **SVO (Subject - Verb - Object)** constituent ordering. It is a head-initial Romance language with moderate pro-drop flexibility and sophisticated clitic positioning rules.

```
Canonical Clause Architecture:
[Subject] + [Clitic Pronouns (Proclisis)] + [Finite Verb] + [Clitic Pronouns (Enclisis)] + [Direct / Indirect Objects] + [Prepositional / Adverbial Modifiers]
```

### Core Syntactic Exemplars:
- *O estudante lê o livro com atenção.* ("The student reads the book with care.") - SVO
- *Eles entregaram a encomenda ao cliente ontem.* ("They delivered the package to the client yesterday.") - SVO + IO + Adv

---

## 2. Pronominal Clitic Placement (Colocação Pronominal)
Portuguese features three distinct positions for object clitic pronouns (*me, te, se, o/a, lhe, nos, vos, os/as, lhes*):

1. **Próclise (Pre-verbal)**: Obligatory in the presence of attractors:
   - Negative words: *Não me diga isso.* (NOT *\*Não diga-me*)
   - Subordinating conjunctions: *Quando me chamarem, irei.*
   - Indefinite/relative pronouns: *Alguém te viu.* / *A carta que me enviou.*
   - Adverbs without pause: *Sempre nos encontramos aqui.*
2. **Ênclise (Post-verbal with hyphen)**:
   - Standard in sentence-initial position in European Portuguese (pt-PT): *Disse-me a verdade.* (Grammatically prohibited to start sentences with clitic in standard formal grammar, though common colloquially in Brazilian Portuguese).
   - After infinitives, gerunds, and imperatives: *Para dizer-lhe*, *fazendo-o*, *faça-o*.
3. **Mesóclise (Infixed within future/conditional)**:
   - When the verb is in the Simple Future (*futuro do presente*) or Conditional (*futuro do pretérito*) and no proclitic attractor exists:
   - *Dir-te-ei a verdade.* (I will tell you the truth.)
   - *Far-se-ia um novo acordo.* (A new agreement would be made.)

---

## 3. The Personal Infinitive (Infinitivo Pessoal)
A signature syntactic innovation of Portuguese among Romance languages is the **inflected personal infinitive**, which admits distinct personal suffixes agreeing with an overt or null subject:

| Person | Ending | Exemplar (*fazer*) | Gloss |
| :--- | :--- | :--- | :--- |
| **Eu** | -Ø | para eu fazer | "for me to do" |
| **Tu** | -es | para tu fazeres | "for you to do" |
| **Ele / Você** | -Ø | para ele fazer | "for him to do" |
| **Nós** | -mos | para nós fazermos | "for us to do" |
| **Vós** | -des | para vós fazerdes | "for you all to do" |
| **Eles / Vocês** | -em | para eles fazerem | "for them to do" |

---

## 4. Subjunctive Mood & The Future Subjunctive (Futuro do Subjuntivo)
Unlike French and Italian, Portuguese actively preserves the **Future Subjunctive**, triggered by temporal, conditional, and relative conjunctions referring to hypothetical future events:
- *Se você fizer o trabalho, teremos sucesso.* ("If you do the work, we will have success.")
- *Quando eles chegarem, começaremos a reunião.* ("When they arrive, we will start the meeting.")

---

## 5. Prepositional Contractions & The Crase Rule
Portuguese rigorously contracts prepositions (*de, em, a, por*) with definite articles and demonstratives:
- *de + o = do*, *de + a = da*, *de + este = deste*, *de + aquele = daquele*
- *em + o = no*, *em + a = na*, *em + um = num*, *em + este = neste*
- *a + o = ao*, *a + os = aos*
- **Crase (à / às)**: Fusion of preposition *a* with feminine definite article *a*: *Vou à praia* (NOT *\*Vou a a praia*).
- *por + o = pelo*, *por + a = pela*, *por + os = pelos*, *por + as = pelas*
