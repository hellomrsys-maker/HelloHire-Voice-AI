# Layer 5: Pragmatics & Address Stratification - Portuguese Engine (Português)

## 1. Divergent Address Hierarchies: Brazilian vs. European Portuguese

### Brazilian Portuguese (pt-BR):
```
[Informal / Peer]        -> você / vocês (verbs in 3rd person: você fala)
[Intimate / Regional]    -> tu (verbs in 2nd or 3rd person: tu falas / tu fala)
[Formal / Respectful]    -> o senhor / a senhora (verbs in 3rd person)
[High Formal / Official] -> Vossa Excelência / Vossa Senhoria
```

### European Portuguese (pt-PT):
```
[Intimate / Family / Peer] -> tu (verbs in 2nd person: tu falas)
[Semi-formal / Social]     -> você (treated with caution in pt-PT, sometimes perceived as blunt)
[Null Subject / Title]     -> O senhor / A senhora / O professor / O doutor
[Formal / Deferential]     -> Vossa Excelência
```

## 2. Courtesy Formulas & Polite Softening
- **Por favor / Por gentileza / Se faz favor (pt-PT)**: "Please."
- **Condicional / Imperfeito de Cortesia**: Using Imperfect Indicative or Conditional to soften requests:
  - *Queria pedir um favor...* ("I would like to ask a favor..." - more polite than *Quero*).
  - *Poderia enviar o arquivo?* ("Could you send the file?").
- **Com licença**: Asking for permission or moving past someone.
- **Obrigado (m.) / Obrigada (f.)**: "Thank you" agreeing with the gender of the speaker!

## 3. Epistolary Structure & Business Correspondence

### Formal Business / Academic Register:
- **Salutation**: *Prezado(a) Senhor(a) [Nome]*, / *Estimado(a) Colega*, / *Excelentíssimo(a) Senhor(a)*
- **Opening**: *Escrevo para solicitar...* / *Vimos por meio deste comunicar que...*
- **Valediction**: *Atenciosamente,* / *Cordialmente,* / *Com os melhores cumprimentos,*

### Informal / Personal Correspondence:
- **Salutation**: *Querido(a) [Nome],* / *Olá, [Nome]!*
- **Opening**: *Espero que estejas / esteja bem.*
- **Valediction**: *Um grande abraço,* / *Beijos,* / *Com carinho,*
