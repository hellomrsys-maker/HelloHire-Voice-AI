# Layer 1: Syntactic Structure & Clausal Organization (Turkish Language Engine)

## 1. Canonical Word Order: Head-Final Subject-Object-Verb (SOV)

Turkish is a rigorously head-final, agglutinative, left-branching language. Modifiers systematically precede modified heads, and the finite verb anchors the absolute sentence-final position:

```
[Subject]  -->  [Temporal/Spatial Adjuncts]  -->  [Indirect Object]  -->  [Direct Object]  -->  [Verb / Predicate]
(Özne)          (Zarf Tümleci)                    (Dolaylı Tümleç)        (Nesne)               (Yüklem)
```

### 1.1 Canonical Sentence Example
- *Öğrenci dün kütüphanede yeni kitabı dikkatle okudu.*
  - *Öğrenci* (The student - Subj / Nom)
  - *dün* (yesterday - Temp Adv)
  - *kütüphanede* (in the library - Locative NP)
  - *yeni kitabı* (the new book - Definite Accusative DO)
  - *dikkatle* (carefully - Manner Adv)
  - *okudu* (read - 3sg Past Verb)
  - Gloss: "The student carefully read the new book in the library yesterday."

### 1.2 Information Structure & Pragmatic Scrambling
While the neutral citation order is SOV, constituent order permits pragmatic scrambling according to Discourse Functional conditions:
1. **Topic (Konu)**: Occupies the sentence-initial position.
2. **Focus (Odak)**: Immediately precedes the finite verb (*pre-verbal focus position*). Wh-question words (*Kim, ne, nerede, ne zaman*) must strictly occupy this pre-verbal focus slot.
3. **Background / Afterthought (Art Vurgu)**: Elements placed after the verb are backgrounded, clarifying information already presupposed in discourse.

## 2. Differential Object Marking (DOM / Belirtili Nesne)

Turkish enforces a strict semantic distinction in the accusative case marking of direct objects:
- **Definite / Specific Direct Object**: Obligatorily marked with the Accusative suffix (*-i / -ı / -ü / -u* with buffer *y*).
  - *Kitabı okudum.* ("I read **the** book.")
  - *Ali'yi gördüm.* ("I saw Ali.")
- **Indefinite / Non-Specific Direct Object**: Left unmarked (Nominative form) and strictly bound to the immediate pre-verbal position (syntactic pseudo-incorporation):
  - *Kitap okudum.* ("I did book-reading / I read a book.")
  - \**Dün kitap kütüphanede okudum* (Ungrammatical: unmarked indefinite object cannot scramble away from verb).

## 3. Postpositional Phrasal Architecture (Edat Öbekleri)

Unlike Indo-European languages which employ prepositions, Turkish exclusively utilizes postpositions (*edatlar*), which follow their dependent noun phrase and govern specific cases:

| Postposition | Governed Case | Meaning | Example |
| :--- | :--- | :--- | :--- |
| **için** | Nominative (Pronouns: Genitive) | for, in order to | *başarı için*, *benim için* |
| **ile / -le / -la** | Nominative / Genitive | with, by means of | *arkadaşı ile*, *trenle* |
| **gibi** | Nominative / Genitive | like, as | *çocuk gibi*, *onun gibi* |
| **kadar** | Dative (*-e / -a*) | as much as, until | *akşama kadar*, *bize kadar* |
| **doğru** | Dative (*-e / -a*) | towards | *eve doğru* |
| **göre** | Dative (*-e / -a*) | according to | *bana göre*, *rapora göre* |
| **sonra** | Ablative (*-den / -dan*) | after | *toplantıdan sonra* |
| **önce** | Ablative (*-den / -dan*) | before | *dersten önce* |
| **beri** | Ablative (*-den / -dan*) | since | *dünden beri* |
| **dolayı / ötürü** | Ablative (*-den / -dan*) | because of, owing to | *yağmurdan dolayı* |

## 4. Subordination via Non-Finite Participial Clauses

Turkish does not use finite complementizers equivalent to English "that" (except the Persian loan particle *ki*). Subordinate clauses are formed by nominalizing verbal participles:

### 4.1 Relative Clauses (Sıfat Fiiller)
1. **Subject Participle (*-(y)en / -(y)an*)**: Used when the relativized noun is the subject of the subordinate clause:
   - *Kitabı okuy**an** öğrenci* ("The student who is reading the book").
2. **Object / Non-Subject Participle (*-dik / -ecek* + Possessive)**: Used when the relativized noun is an object or oblique constituent:
   - *Öğrencinin oku**duğu** kitap* ("The book that the student read").
   - *Yarın gör**eceğimiz** film* ("The movie that we will see tomorrow").

### 4.2 Complement Clauses (İsim Fiiller)
- Factive complement clauses use *-dik* + Possessive + Case:
  - *Geldiklerini biliyorum.* ("I know that they came" - *Gel-dik-leri-n-i*).
- Prospective or non-factive clauses use *-me / -ma* or *-mek / -mak*:
  - *Gitmek istiyorum.* ("I want to go").
  - *Gelmene sevindim.* ("I was pleased at your coming").
