# Telugu Linguistic Layer 2: Morphological Analysis (Word Layer)
## తెలుగు పద నిర్మాణ వ్యవస్థ (Morphology)

Telugu morphology is predominantly **agglutinative (సంశ్లేషణాత్మకము)**, chaining nominal case markers (విభక్తులు), verbal tense-aspect-mood suffixes (కాల, భావ, పురుష ప్రత్యయాలు), and postpositions onto nominal and verbal bases without obliterating morpheme boundaries.

---

### 1. Nominal Case Morphology: The 8 Vibhaktulu (విభక్తి వ్యవస్థ)
Nouns in Telugu inflect through eight canonical morphological case paradigms:

| విభక్తి (Case) | ప్రత్యయాలు (Affixes) | కారకార్థం (Semantic Role) | ఉదాహరణ (Example) |
| :--- | :--- | :--- | :--- |
| **ప్రథమ (Nominative)** | డు, ము, వు, లు | కర్త (Agent / Subject) | `రాముడు`, `వృక్షము` |
| **ద్వితీయ (Accusative)** | నిన్, నున్, లన్, గురించి | కర్మ (Direct Patient) | `రాముని`, `పుస్తకాన్ని` |
| **తృతీయ (Instrumental)** | చేతన్, చేన్, తోడన్, తోన్ | కరణము / తోడు (Instrument/Comitative)| `కత్తితో`, `మిత్రుడితో` |
| **చతుర్థి (Dative)** | కొరకున్, కై | సంప్రదానము (Beneficiary/Purpose) | `దేశం కొరకు`, `విద్యకై` |
| **పంచమి (Ablative)** | వలనన్, కంటెన్, పట్టి | అపాదానము (Source/Comparison) | `సత్యం వలన`, `అతని కంటె` |
| **షష్ఠి (Genitive)** | కిన్, కున్, యొక్క, లోపలన్ | సంబంధము (Possessor/Locative Rel) | `నా యొక్క`, `ఇంటిలో` |
| **సప్తమి (Locative)** | అందున్, నన్ | అధికరణము (Spatial/Temporal Location)| `హృదయమందు`, `యుద్ధమున` |
| **సంబోధన ప్రథమ (Vocative)**| ఓ, ఓయి, ఓరీ, ఓసీ | సంబోధన (Direct Address) | `ఓ రాముడా!`, `ఓయి మిత్రమా!`|

### 2. Sandhi Morphophonemic Coalescence (సంధి ప్రక్రియ)
Sandhi rules in Telugu govern phonological transformations at word and morpheme junctures:
1. **ఉత్వ సంధి**: Obligatory elision of short `u` before a following vowel:
   $$\text{రాముడు} + \text{ఇతడు} \longrightarrow \text{రాముడితడు}$$
2. **గసడదవాదేశ సంధి**: Softening of unvoiced stops $(k, c, t, t, p \rightarrow g, s, d, d, v)$ following nominative forms:
   $$\text{వాడు} + \text{కొట్టె} \longrightarrow \text{వాడు గొట్టె}$$
3. **సవర్ణదీర్ఘ సంధి**: Vowel lengthening between identical vowels:
   $$\text{విద్యా} + \text{ఆలయము} \longrightarrow \text{విద్యాలయము}$$
