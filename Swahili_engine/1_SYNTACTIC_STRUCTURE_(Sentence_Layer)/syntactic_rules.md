# Swahili Engine — Layer 1: Syntactic Structure (Sentence Layer)

## 1. Clausal Typology: Head-Initial SVO & Alliterative Concord

Swahili (*Kiswahili*) is a canonical head-initial, dependent-marking, agglutinative Bantu language characterized by pervasive grammatical concord:

### 1.1 Canonical Word Order (SVO)
The basic sentential word order is Subject - Verb - Object:
```
[Subject - Kiima]        [Verb - Kiitenzi]        [Object - Shamirisho]
     Watoto                wanasoma                    vitabu.
  (Children [Cl 2])       (they-PRES-read)          (books [Cl 8])
```

### 1.2 Pervasive Noun Class Concord (Upatanisho wa Kisarufi)
Every modifier (adjective, demonstrative, possessive, associative particle, relative pronoun) and the governing verb predicate must obligatorily agree with the governing noun's class:
```
[Kitabu]    [changu]       [hiki]          [kizuri]        [kilianguka].
 Noun-Cl7  Poss-Cl7-my   Dem-Cl7-this    Adj-Cl7-good    Verb-Cl7-fell
"This good book of mine fell."
```
If pluralized into Class 8:
```
[Vitabu]    [vyangu]       [hivi]          [vizuri]        [vilianguka].
 Noun-Cl8  Poss-Cl8-my   Dem-Cl8-these   Adj-Cl8-good    Verb-Cl8-fell
"These good books of mine fell."
```

---

## 2. Post-Nominal Modifier Hierarchy (Mpangilio wa Virai Nomino)

Within the Swahili noun phrase (NP), modifiers strictly follow the head noun in a rigid hierarchy:
```
[Noun] > [Possessive] > [Demonstrative] > [Adjective] > [Numeral] > [Relative Clause]
```
Example:
- *Mtoto wangu huyu mdogo aliyekuja...*
  (*Mtoto* [Child] + *wangu* [my] + *huyu* [this] + *mdogo* [small] + *aliyekuja* [who came]...)

---

## 3. Pro-Drop & Pronominal Incorporation

Swahili is an extreme **pro-drop language**:
- The subject noun or personal pronoun is almost always omitted in neutral discourse because the verb's obligatory Subject Prefix (**SP**) uniquely marks the person, number, and noun class:
  - *Ninasoma kitabu.* ("I am reading a book" — *Mimi* dropped).
  - *Watafika kesho.* ("They will arrive tomorrow" — *Wao* dropped).
  - *Kilianguka.* ("It [Class 7 object] fell").
- If the overt subject pronoun (*mimi, wewe, yeye, sisi, ninyi, wao*) is inserted, it carries pragmatic focus or topical emphasis:
  - *Mimi ninasoma, lakini wewe unalala.* ("*I* am reading, but *you* are sleeping.")

---

## 4. Verbal Argument Incorporation: Object Prefixes (Viwakilishi vya Mtendwa)

In addition to the subject prefix, Swahili verbs optionally or obligatorily incorporate an Object Prefix (**OP**):
1. **Definite / Specific Objects**: When the direct object is definite, specific, or topical, the corresponding OP is inserted into the verbal template:
   - *Niliona kitabu.* ("I saw a book" — indefinite, no OP).
   - *Nili**ki**ona kitabu.* ("I saw **the** book" — definite, Class 7 OP *-ki-* inserted).
2. **Animate Objects (Classes 1/2)**: For human/animate referents, the object prefix (*-m- / -wa-*) is **obligatory**:
   - *Nili**m**wona Juma.* ("I saw Juma" — obligatory *-m-*).
   - *\*Niliona Juma* (Ungrammatical in standard Swahili).

---

## 5. Verbal Derivational Extensions (Mnyambuliko wa Vitenzi)

Swahili verbs expand their syntactic valence through productive agglutinative suffixes placed directly before the final vowel (*-a*):
1. **Applicative (*Kutendea*)**: Suffix `-ia / -ea` (Benefactive, Malefactive, Instrumental, Locative):
   - *andika* (write) $\to$ *andik**ia*** (write to/for someone).
2. **Causative (*Kutendesha*)**: Suffix `-isha / -esha / -za`:
   - *soma* (read) $\to$ *som**esha*** (teach / cause to read).
3. **Passive (*Kutendwa*)**: Suffix `-wa`:
   - *penda* (love) $\to$ *pend**wa*** (be loved).
4. **Reciprocal (*Kutendana*)**: Suffix `-ana`:
   - *penda* (love) $\to$ *pend**ana*** (love one another).
5. **Stative / Neuter (*Kutendeka*)**: Suffix `-ika / -eka`:
   - *vunja* (break) $\to$ *vunj**ika*** (be broken / breakable).
