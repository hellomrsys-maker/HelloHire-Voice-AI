# Syntactic Structure & Grammar Rules for Dutch (Sentence Layer)
## Sovereign Engine: `Dutch_engine` | Germanic V2 / SOV Asymmetry

### 1. The V2 / Verb-Final Clause Asymmetry
Dutch is fundamentally an underlying **SOV (Subject - Object - Verb)** language exhibiting the classic Germanic **Verb-Second (V2)** constraint in main clauses and **Verb-Final (SOV)** in subordinate clauses:

$$\text{Main Clause} \to \text{Constituent}_1 + \text{Verb}_{\text{Finite}} + \text{Subject/Middle Field} + (\text{Verb}_{\text{Non-finite}})$$
$$\text{Subordinate Clause} \to \text{Complementizer} + \text{Subject} + \text{Middle Field} + \text{Verb Cluster}$$

#### Examples:
1. **Canonical Main Clause (S-V2-O)**:
   *Jan leest het boek.* ("Jan reads the book.")
2. **Inverted Main Clause with Topicalized Adverb (Adv-V2-S-O)**:
   *Gisteren las Jan het boek.* ("Yesterday read Jan the book.")
3. **Subordinate Clause with SOV Verb-Final Cluster**:
   *... omdat Jan het boek heeft gelezen.* ("... because Jan has read the book.")

---

### 2. Separable Verb Syntax (*Scheidbare Werkwoorden*)
Prepositional and adverbial prefixes detach from the verb root in main finite clauses and move to clause-final position:
- Infinitive: *opbellen* ("to call up / phone")
- Main Clause: *Ik bel mijn vriend op.* ("I call my friend up.")
- Subordinate Clause: *... omdat ik mijn vriend opbel.* ("... because I call my friend up.")
- Past Participle: *opgebeld* (*ge-* infixed between prefix and root).

---

### 3. Sentence Frame & Negation: *Niet* vs *Geen*
- **Geen**: Negates indefinite nouns (replaces *een* or uninflected bare nouns):
  - *Ik heb geen auto.* ("I have no car / I don't have a car.")
- **Niet**: Negates verbs, adjectives, adverbs, and definite noun phrases:
  - *Ik lees het boek niet.* ("I do not read the book.")
  - *Hij is niet thuis.* ("He is not home.")

---

### 4. Passive Voice: *Worden* vs *Zijn*
- **Imperfective / Dynamic Passive**: *worden* + past participle (*Het huis wordt gebouwd* - "The house is being built").
- **Perfective / Stative Passive**: *zijn* + past participle (*Het huis is gebouwd* - "The house has been built / is built").
