# Layer 4: Semantic Representation (Meaning Layer) — Spanish Engine

## 1. Dual Copula Architecture: Ser vs Estar
Spanish separates predicate existence into two complementary ontological verbs:

### 1.1 Invariant Semantic Domains
| Dimension | **Ser** (Essence, Identity, Categorization) | **Estar** (State, Location, Condition) |
| :--- | :--- | :--- |
| **Origin & Nationality** | *Soy de Colombia.* | — |
| **Identity & Profession** | *Ella es ingeniera.* | — |
| **Inherent Characteristics** | *La nieve es fría.* | — |
| **Spatial Location** | *El concierto es en el estadio.* (Events) | *El estadio está en la ciudad.* (Physical objects) |
| **Temporary State / Health**| — | *Estoy cansado.* / *Está enfermo.* |
| **Resulting Condition** | — | *La puerta está abierta.* |
| **Progressive Aspect** | — | *Está escribiendo un informe.* |
| **Passive Voice** | *Fue construido por romanos.* (Action) | *Está construido de piedra.* (Resulting state) |

### 1.2 Adjectival Semantic Shift Matrix
Certain adjectives undergo complete lexical-semantic shifts depending on copula selection:
- *ser listo* (clever/intelligent) $\neq$ *estar listo* (ready/prepared).
- *ser bueno* (virtuous/high quality) $\neq$ *estar bueno* (tasty/healthy).
- *ser malo* (wicked/poor quality) $\neq$ *estar malo* (sick/spoiled).
- *ser aburrido* (boring personality/thing) $\neq$ *estar aburrido* (feeling bored).
- *ser rico* (wealthy) $\neq$ *estar rico* (delicious).
- *ser verde* (green-colored) $\neq$ *estar verde* (unripe/inexperienced).
- *ser atento* (courteous) $\neq$ *estar atento* (attentive/paying attention).

## 2. Prepositional Semantics: Por vs Para
The distinction between cause/means (*por*) and destination/purpose (*para*):

### 2.1 Domain Mapping
| Function | **Por** | **Para** |
| :--- | :--- | :--- |
| **Cause / Reason** | *Cancelaron el vuelo por la lluvia.* | — |
| **Purpose / Goal** | — | *Estudio mucho para aprobar el examen.* |
| **Duration / Span** | *Viví en Valencia por tres años.* | — |
| **Deadline / Target Time**| — | *El informe es para el viernes.* |
| **Recipient** | — | *Este regalo es para ti.* |
| **Exchange / Price** | *Lo compré por cincuenta euros.* | — |
| **Through / Along** | *Caminamos por la playa.* | — |
| **Destination** | — | *Salgo para Barcelona.* |
| **Passive Agent** | *Pintado por Picasso.* | — |
| **Standard / Comparison**| — | *Para ser principiante, toca muy bien.* |

## 3. Idiomatic Expressions (*Frases Hechas & Modismos*)
Spanish semantic analysis incorporates formulaic figurative idioms:
1. *Tomar el pelo* $\to$ Tease or pull someone's leg.
2. *Costar un ojo de la cara* $\to$ Exorbitantly expensive.
3. *Estar en las nubes* $\to$ Daydreaming or absent-minded.
4. *Dar en el clavo* $\to$ Hit the nail on the head / exactly right.
5. *Meter la pata* $\to$ Commit a blunder / faux pas.
6. *Hacer la vista gorda* $\to$ Turn a blind eye.
7. *Tirar la toalla* $\to$ Give up / surrender.
8. *Ahogarse en un vaso de agua* $\to$ Make a mountain out of a molehill.
